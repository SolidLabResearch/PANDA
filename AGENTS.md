# Codex repository instructions

When inspecting this repository, do not read or summarize files that are ignored by `.gitignore`, unless the user explicitly asks for one of those files.

In particular, avoid:
- node_modules/
- dist/
- build/
- coverage/
- logs/
- benchmark-results/
- benchmarks/results/runs/
- benchmarks/results/environment/
- scratch/
- .internal/
- .vscode/
- *.log
- *.tmp
- *.csv generated by benchmarks
- query_audit_log.json

For benchmark work, prefer these source files first:
- scripts/benchmark/run_all_scenarios.js
- scripts/benchmark/validate_results.js
- scripts/benchmark/aggregate_results.js
- scripts/benchmark/live_spo2_replayer.js
- benchmarks/scenarios/*.json
- src/server/HTTPServer.ts
- src/server/WebSocketHandler.ts
- src/server/NotificationTopicResolver.ts
- src/service/authorization/
- src/service/aggregator/
- src/utils/benchmark/

Do not inspect generated benchmark run outputs unless the user provides a specific benchmark ID or file path.
